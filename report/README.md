# Estimating the Economic Impact of Internet Disruptions and Shutdowns on Digital Businesses and Startups in Iran

## Overview

This repository contains the source files for the research project entitled:

**"Estimating the Economic Impact of Internet Disruptions and Shutdowns on Digital Businesses and Startups in Iran"**

The project is conducted as part of the **Macroeconomics** course and aims to estimate the economic consequences of internet disruptions on Iran's digital economy using quantitative and econometric methods.
